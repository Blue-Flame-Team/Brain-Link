# 📝 تقرير مجلد `lib/helpers/` بالتقصيل (Helpers Folder)

## 🎯 وظيفة المجلد
مجلد `helpers` هو المجلد المسؤول عن توفير "دوال مساعدة" ووظائف مساندة لا تعتمد بشكل رئيسي على واجهة المستخدم (UI)، وظيفتها تقديم حلول سريعة ومكررة للتعامل مع العمليات الشائعة كقواعد البيانات المحلية، التفضيلات المخزنة (Shared Preferences)، وفتح الملفات بأنواعها.
فصل هذه الوظائف داخل `helpers` يضمن نظافة الأكواد بالـ UI ويجعلنا قادرين على استدعائها في أي مكان بالبرنامج بكتابة سطر واحد.

## 📄 تفصيل الأكواد والملفات

### 1- ملف `db_helper.dart`
**وظيفته:**
هو المدير الأساسي لقاعدة بيانات الجوال المدمجة `SQLite` عبر حزمة `sqflite`. يُستخدم بشكل حصري لتخزين البيانات محلياً للرجوع إليها وقت فصل الإنترنت أو للإجراءات المتعلقة بالمحتوى الذي يحتفظ به المستخدم (مثل الإعجابات المحفوظة أو بيانات جلسة تسجيل الدخول).

**ما بداخل الكود ולماذا صمم هكذا؟**
- يعتمد على النمط التصميمي `Singleton Pattern` كالتالي:
  `static final DbHelper instance = DbHelper._internal();`
  نجد هنا تعريف `_internal()` وهو لضمان أننا نفتح اتصالاً واحداً فقط للـ Database وتفادي تدمير البيانات عند استدعائها بأكثر من مكان بنفس الوقت.
- `_initDb()`: يتم إنشاء الجدول `users` والذي يحتوي (id, fullName, email) لتخزين المستخدم كنسخة محلية.
- ويتم إنشاء جدول مخصص `favorites` يحتوي جميع تفاصيل البوست كصيغة (SQL Table) كـ (id, authorId, authorName, timeStamp, content, إلخ).
- دوال مثل `insertFavorite`, `deleteFavorite`, `isFavorite`, `getFavorites`: هذه دوال جاهزة للتأكد وإضافة أو حذف المنشور من قاعدة البيانات لتبسيط العملية بداخل `home_tab.dart`.

### 2- ملف `file_handler.dart`
**وظيفته:**
عبارة عن وسيط ومساعد استثنائي لتحميل، قراءة، وفتح أية ملفات تردنا من الخادم الخارجي. يعالج خصيصاً الملفات القادمة من Firebase Realtime Database.

**ما بداخل الكود ولماذا نستخدمه؟**
يُعرف داخله كلاس فيه دالة وحيدة ومهمة جداً:
`static Future<void> openFile(...)`
- لماذا احتجنا إليه؟ لأن بعض مسارات مكتبتنا وملفات الشات ترفع مباشرة بطريقة فك التشفير Base64.
- الدالة تفحص ما إذا كان الرابط يبدأ بـ `rtdb://` (بروتوكول مصطنع خصيصاً للتطبيق):
  - تذهب لـ FirebaseDatabase وتسحب الـ String الطويل.
  - تقوم بفك شفرته (Decode) باستخدام `base64Decode` لتحويله إلى بايتس (bytes).
  - إذا كان المتصفح يعمل نسخة ويب (`kIsWeb`) يتم خلق رابط BaseURI.
  - إذا كان جوال، يستدعي `getTemporaryDirectory()` ليحفظ فيه الملف ثم يمرره لمكتبة كـ `OpenFilex` ليتم فتح مستند الـ PDF أو الصورة في عارض الهاتف.
- وإذا لم يكن الرابط محلي (بل رابط Http عادي)، يعطيه لـ `launchUrl` لتفتحه بالمتصفح.

### 3- ملف `shared_pref_helper.dart`
**وظيفته:**
استخدام الـ `SharedPreferences` للتعامل مع الحالات الخفيفة (Key/Value pairs) كمعرفة هل المستخدم حاليا مسجل دخول؟ وما هو البريد الإلكتروني المحفوظ؟.

**ما بداخل الكود ولماذا నستخدمه؟**
- يُعرّف مفاتيح نصية `_emailKey`, `_isLoggedInKey`.
- دالة `setUser` و `setLoggedIn` لحفظ النص و الـ bool (صواب/خطأ).
- `isUserLoggedIn()` لمعرفة هل نستمر في إدخاله للصفحة الرئيسية أم نرجعه للتسجيل بدون الاضطرار لاستشارة فايربيس (يقلل الطلبات العشوائية وتسريع الواجهة).

---
**الخلاصة:**
كل ملف في الـ `helpers` يفصل وظائف تكرارية أساسية كالـ (Caching, I/O Device Handling, Configuration). هذه البنية تسهل التعامل مع متطلبات النظام دون تلويث منطقة عرض البيانات.
